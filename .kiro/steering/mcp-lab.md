# 이 폴더에서 개발할 때 지킬 것 (mcp-lab 실습)

의료·바이오 분야 수강생의 실습 폴더다. 사용자는 개발 경험이 많지 않을 수 있다. 한국어로, 쉬운 말로 답하고, 바꾼 파일과 확인한 결과를 짧게 알려 준다.

## 실행 방법

- 파이썬은 항상 이 폴더의 가상환경으로 실행한다: `.venv/bin/python 파일.py`. `python`, `python3`, `pip install`을 그대로 쓰지 않는다.
- 패키지가 더 필요하면 설치하지 말고, 무엇이 왜 필요한지 먼저 사용자에게 말한다.
- 모델은 내 컴퓨터의 Ollama에서 돈다 (`gemma4:e4b`, `bge-m3`). 유료 API나 외부 AI 서비스를 붙이지 않는다. 연결이 안 되면 Ollama 앱이 켜져 있는지 확인해 달라고 한다.
- 모델을 새로 받는 일(`ollama pull`)과 증류 학습(`mlx_lm lora`, `train_student`)은 오래 걸리고 컴퓨터가 뜨거워진다. 하기 전에 반드시 사용자에게 묻는다.
- 전문가 팀을 한 번 돌리면 30초~2분 걸린다. 확인은 한 번에 질문 하나로 하고, 같은 것을 반복해서 돌리지 않는다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `agent_team.py` | Multi-Agent 팀의 틀 (`Team`). 전문가 고르기, 동시에 일 시키기, 답 합치기, 증류. **되도록 고치지 않는다** |
| `lab_ui.py` | 진행 상황과 답을 화면에 보여 주는 도우미. 고치지 않는다 |
| `xray_team.py` | 완성 예시: 흉부 엑스레이 판독 보조 팀. 새 팀을 만들 때 본보기로 읽는다 |
| `my_team.py` | 수강생이 만드는 팀. **주로 이 파일을 고친다.** 없으면 `xray_team.py`를 본보기로 새로 만든다 |
| `team_service.py` | 팀을 웹 화면이나 MCP 서버로 띄운다 |
| `drug_tools.py`, `drug_agents.py` | 신약 후보 검토 예시의 도구와 팀 |
| `example/*.ipynb` | 수업 노트북. 부탁받지 않으면 고치지 않는다 |
| `data/`, `distill/` | 예시 자료, 증류 데이터와 학습 결과 |

## 팀 파일 쓰는 법

팀 파일에는 `TEAM = Team(...)`이 있어야 한다. 증류까지 하려면 `SUBJECTS`, `TRAIN_TEMPLATES`, `TEST_TEMPLATES`도 둔다.

- 도구는 평범한 파이썬 함수다. 인자에 타입을 적고, 설명글(docstring)에 언제 쓰는지와 예시를 적는다. Agent는 이 설명글을 보고 도구를 고른다.
- 전문가는 `experts={"키": {"title", "role", "prompt", "tools"}}`로 적는다. `role`은 지휘자가 누구에게 보낼지 정할 때 읽는 글이다. 전문가끼리 역할이 겹치지 않게 쓴다.
- 도구가 외부 자료를 가져오면 실패했을 때 지어내지 말고 "확인하지 못함"을 돌려주게 한다.

## 고친 뒤 확인하기

```bash
.venv/bin/python -c "from my_team import TEAM; r = TEAM.ask('질문'); print(r['experts']); print(r['answer'])"
```

- 불린 전문가(`experts`)와 각자 쓴 도구(`results[*]['tools']`)가 의도와 맞는지 본다.
- 웹 화면: `.venv/bin/python team_service.py my_team` → http://localhost:8000. 서버는 끝나지 않는 명령이므로 사용자에게 새 터미널에서 실행해 달라고 하거나 백그라운드로 띄운다.

## 의료 자료를 다룰 때

- 실제 환자의 사진, 이름, 검사 결과를 넣지 않는다. 공개 자료나 지어낸 예시만 쓴다.
- 답변과 리포트는 교육·연구용이다. 진단이나 처방처럼 단정하지 않고, 사람이 확인할 것을 적는다.
- 숫자와 사실은 도구 결과에 있는 것만 쓴다.

## 하지 않는 것

- `git push`, 파일 삭제(`rm`), `setup.sh` 수정은 사용자가 직접 부탁했을 때만 한다.
- `distill/`의 학습 결과와 `data/cache/`를 지우지 않는다.
